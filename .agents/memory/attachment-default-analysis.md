---
name: Attachment default analysis
description: How document attachments should behave when the user supplies only a title versus an explicit task.
---

**Rule:** When a user attaches a document with no instruction or only a clearly recognizable title/filename, respond with exactly one substantive natural paragraph—enough to show attentive understanding and engagement, not merely receipt. Any explicit task, including read/note/store-only, remains controlling.

**Why:** The user expects uploading a document with only a title to produce useful engagement, but explicitly rejected a fixed summary/facts/timeline/risks/next-steps formula as inorganic.

**How to apply:** Preserve explicit instruction precedence. Use the one-paragraph default only when there is unequivocally no task; lead with what matters in that document, avoid headings/checklists, and retain source discipline.
